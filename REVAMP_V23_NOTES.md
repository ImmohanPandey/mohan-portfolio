# Portfolio V2.3

## Hero motion
- Restored left/right/top/bottom pointer parallax on the portrait.
- Pointer tracking lives on the fixed hero visual container; only an inner portrait layer transforms.
- Uses spring-smoothed x/y + rotateX/rotateY values, avoiding the old moving-hover-hitbox flicker.
- Touch devices stay static; reduced-motion users get no parallax.

## Project visuals
Added four local, name-free futuristic SVG scene assets:
- Inventory / operations: neon warehouse and data visualization.
- Healthcare: medical diagnostics, secure data rings and pulse visualization.
- Food delivery: burger, pizza, phone silhouette and delivery-route energy.
- Admin / automation: profile/workflow/control-room visualization.

Project artwork now sits behind a compact engineering console and receives controlled hover depth/zoom treatment.

## Product-name privacy
- Removed the product/app name from hero and journey UI.
- Current journey project is explicitly shown as `Vautra`, with designation `Senior Software Developer`.
- Artwork contains no product or app branding.
